# RR-21 — Landing Page, Meta & Shareability

**Audit:** Release Readiness (40-agent) · Wave 3 · Mission RR-21 · 2026-09-12
**Skills:** copywriting + cRo (value-prop/CTA critique); first 30 seconds for a brand-new visitor arriving from a shared link.

Verified prior flags first: OG/robots/sitemap still absent (RR-01 confirmed), socket.io parser-block + no compression + theme flash still present (full-codebase-audit 7.9/7.5/R3), `theme-color` did get added since agent-ui-review. Going deeper below.

## Findings (15)

1. **[BLOCKER] `public/index.html:3-11`** — Entire social/SEO head is missing: `og:title|description|image|url`, `twitter:card`, `meta description`, `canonical`, `apple-touch-icon`, manifest. Discord/WhatsApp preview = bare title-only text link ("Poorup — After-Hours Game Parlor"), no image, no snippet. Share click-through collapses. Fix: add OG/Twitter block + absolute 1200×630 raster OG image (SVG favicons aren't rendered by most scrapers) + meta description + apple-touch-icon 180×180.
2. **[BLOCKER] `public/clientRoomShare.js:44-49` + `public/main.js:871-877`** — No invite deep link. Share copies a bare 6-char code with no URL; public rooms return silently (no copy, no toast). A shared URL lands the recipient on the home screen with zero room context; they must click Join → type code → type name. Fix: share `https://host/?join=CODE` plus a message; parse `?join=` on load to prefill/open the join modal (auto-join when a seat is open).
3. **[MAJOR] `public/clientRoomsUi.js:432-440,463-466` + `clientProfileRender.js:641-648`** — First click on the primary CTA fails for every new guest: "Create & Host Table" closes the modal, reverts home, and shows "CREATE AN ALIAS BEFORE JOINING A TABLE." (wrong verb for Create), focusing the alias field. Join modal collects the name inline (`index.html:290-293`); Create doesn't. Guest identity is also contradictory ("that's you, PLAYER" then "create an alias"). Fix: collect the player name inside the create modal like Join does (or auto-generate and let them rename), never bounce with an error.
4. **[MAJOR] `public/index.html:165-169` + `clientLobbyUi.js:670-683,520`** — No solo path from the landing. Quick Table finds/creates a public room; if nobody else is online you sit alone (bots default 0), and CPU seats hide behind "Bots — Reserve CPU seats for Solo Dev Mode" deep in the in-room settings rail. A Discord visitor at midnight can't actually play. Fix: landing CTA "Play vs CPU" = create + reserve 1–3 bots + start, and rename "Solo Dev Mode" to player language.
5. **[MAJOR] `public/index.html:6-9` + `public/main.js:1053` + `clientThemeRender.js:123-129`** — Theme flash: tokens are applied to `body` inline only after the ~40-module graph boots, so saved non-original themes paint dark-original first; `data-theme-color` meta is never updated by any JS (static `#01070a`). Fix: tiny blocking inline script in `<head>` that reads `poorup.theme.id.v2`, sets `data-theme-id`/tokens before CSS paint; update `theme-color` on change.
6. **[MAJOR] `public/styles.css:2934-2949,3661-3667` + `index.html:129-189`** — At 390px the static sky-atmosphere band (~78px) plus kicker/wordmark/tagline/copy/status strip push the first CTA to roughly 600–650px down; on 667px-tall phones (iPhone SE) all three CTAs are below the fold, and the you-chip is hidden (`styles.css:3596`). Link-shared phone users see text, no button. Fix: ≤720px order entry desk first (or anchor a CTA beside the wordmark) and cut the hero copy.
7. **[MAJOR] `public/index.html:8-9` + `server/server.js:69` + `package.json:19`** — First paint waits on 232KB styles.css + parser-blocking 155KB socket.io client, both un-gzipped (no `compression`, no `maxAge`), then a module waterfall; no `noscript`/loading state, so CTAs look live but are inert. Fix: gzip/brotli middleware, move socket.io to body end with `defer` (min build), `modulepreload` main.js, disable CTAs until bound (or inline `aria-disabled` + "loading" copy).
8. **[MAJOR] `public/index.html:131,193-198`** — No trust layer: no footer, About/how-to-play, contact, privacy/terms, or GitHub link; the only credibility cue is the aria-correct but cryptic "POORUP v2.4.1 — insert coin". Public-demo visitors have no way to verify what this is or who made it. Fix: slim footer (About, How to play, GitHub, contact, Privacy/Terms placeholders, version) — release dependency.
9. **[MINOR] `public/index.html:10,133`** — `<title>` and h1 never say what the product is: category keywords ("online board game", "multiplayer", "with friends", "no sign-up") are absent from both, so search results and embeds can't self-explain. Fix: "Poorup — Play a free multiplayer property board game in your browser" (keep the parlor voice in the subhead).
10. **[MINOR] `public/index.html:61,99,175` + `clientProfileRender.js:604-618`** — Static shell ships a fabricated identity (`guest_4412`, `--:--`) that JS replaces with "PLAYER" (or real alias) on boot — visible content swap and a fake "you" before the real default exists. Fix: neutral placeholder ("guest", empty avatar with fixed size) or inline bootstrap the alias.
11. **[MINOR] `public/index.html:157,164,166-168,174,222,277`** — Terminology drift on one screen: room / table / parlor / lobby / "west seat" / alias / identity / name all describe the same concepts ("LOBBIES — LOBBIES" initial value, "press [B] to browse rooms", "Quick table", "Create & Host Table"). Fix: pick one noun per concept (room = instance, seat = player slot, parlor = product world) and apply to CTAs and status labels.
12. **[MINOR] `server/server.js:70-75` + missing `public/robots.txt`/`sitemap.xml`** — Wildcard `app.get('*')` returns `index.html` 200 for `/robots.txt`, `/sitemap.xml`, and every unknown path (masks 404s, unknown 1.16). Crawlers index the app shell at junk URLs. Fix: real robots.txt + sitemap.xml served before the wildcard; return 404 for unmatched non-navigation paths.
13. **[MINOR] `public/index.html:21,35-70,144-160` + `styles.css:875-879`** — A11y quick pass: keyboard users cross ~15 focusables (6 nav tabs, you-chip, 2 audio toggles, 3 signal buttons) before the first CTA; h1 is brand-only; `SHIFT+P` hint is `aria-hidden` (known 6.10) so Night Shift is undiscoverable to SR; you-chip hidden <768px leaves only the below-fold chair for identity. Skip link works, headings/landmarks otherwise sound. Fix: reorder/roledown nav, move the hint into the announced status, expose a "play" shortcut.
14. **[MINOR] `public/index.html:137,141-143`** — Copy claim "Usually around twelve minutes" is a mock statistic (PRODUCT.md forbids invented claims) and "feed the vacation pot" is inside jargon; "FOUR SEATS · ONE BANK · NO REFUNDS" is the clearest line on screen but sits above the weaker paragraph. Fix: drop/soften the time claim, lead with the concrete loop ("roll, buy, charge rent — last wallet standing wins").
15. **[MINOR] `public/index.html:45-53` vs `styles.css:2913`** — No gameplay preview or "how it works" near the CTA: RULES is the 6th top-nav tab, off-screen in the phone scroll strip; a cold visitor must commit without seeing the board. Fix: secondary text link under the CTAs ("See how a round plays" → `?rules=book`) and a 3-bullet how-it-works line.

## 5 fastest changes for share→play conversion
1. **Share card** (finding 1): OG/Twitter + image + description — turns every posted link from bare text into an embed.
2. **Invite link** (2): `?join=CODE` + share text; make the ROOM button copy the URL.
3. **Fix the first guest click** (3): name inline in Create, or auto-alias; never error-bounce.
4. **Solo path** (4): "Play vs CPU" one-click on the landing + rename "Solo Dev Mode".
5. **Phone + first paint** (6/7): CTA first at ≤720px, gzip + defer socket.io, inline theme bootstrap.

## First-time visitor checklist

| Step | What they see today | What's missing |
|---|---|---|
| Discord/WhatsApp link | Bare title text link, no image/snippet | og:image/description, twitter:card, canonical, meta description |
| Click → static shell | Dark-original theme (flash if theme saved), placeholder "guest_4412"/"--:--", empty sprite logos, "CONNECTING…" | Inline theme bootstrap, real/neutral placeholder, logo pre-hydration |
| Desktop hero | Wordmark, "FOUR SEATS · ONE BANK · NO REFUNDS", 2-line pitch, ENTRY "NO ACCOUNT" strip, then CTAs | Category in title/h1, how-it-works preview, footer/trust |
| Phone (390px) | Hero copy first; CTAs at/below fold; no you-chip | CTA above fold, identity visible |
| First action | Create Room → modal → error bounce to alias; Join works (name inline); Quick Table can strand you alone | Inline naming for Create, one-click CPU play |
| In a room | Room code copy = bare code (public = silent no-op) | Invite URL, share text, feedback for public rooms |
| Footer | Nothing (ticker only) | About/How to play, contact, legal, GitHub, version |
