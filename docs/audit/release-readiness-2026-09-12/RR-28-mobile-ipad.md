4. **[MAJOR]** `public/styles.css:2631-2637` vs `:2691-2694` — desktop 1280–1535 (e.g. common 1366×768 laptop) — HUD stays 2-col × 3 rows = **428px**, starving the height-led board: probe board **232×232 @1366×768 (~17px tiles), 264 @1280×800, 364 @1440×900**, then jumps to 624 at 1536 — move the 5-col HUD rule (with `minmax(0,1fr)`) down to 1280 or auto-compact when board-area < ~480px.
5. **[MAJOR]** `public/styles.css:814,832,1858,2982,1448,1821,2608,3798` — phones/tablets — key targets under 44px: game topnav buttons 40px (`:814`), audio toggles 42×40 (`:832`), rail tabs 38px (`:1858`), phone nav tabs 34px (`:2982-2983`; 44px only inside tablet block `:4111`), event votes 28px (`:1448`), jail action 32px (`:1821`), auction pass 38px (`:2608`), log filters 30px (`:3798`) — hoist a `@media (pointer:coarse)` 44px floor out of the 1279 cap.

## Recommended release posture
- **Fix before release if mobile is claimed supported:** #1 phone-landscape guard (one media-query condition), #4 HUD 5-col at 1280 (desktop-primary laptops), #6 coarse-pointer touch-action + #5 44px floor hoist, #7 music state. Known 3.9 topnav and 4.1/4.2 iPad-Pro cliff next.
- **Explicitly not supported:** phone-landscape play and Night Shift on touch-only. **Do not hard-block** room join/chat on phones — shared links are the acquisition path; degrade + reconnect already handle reloads.
- **Visible "best on desktop" notice:** show in `#view-game` for `(max-width:767px)`, `(orientation:portrait) and (max-width:1279px)`, and `(orientation:landscape) and (max-height:500px)` — e.g. "Best on desktop or landscape iPad; some controls require scrolling."
