## Findings

1. [MINOR] `package.json:19` (express) — npm `latest` is 5.2.1; repo correctly stays at latest 4.x (4.22.2, `latest-4`). Express 5 would break `app.get('*')` at `server/server.js:70` (path-to-regexp v8 requires named wildcard `/*splat`) plus body-parser 2 semantics — release impact none while pinned; an accidental major bump (e.g. `npm audit fix --force`) breaks catch-all routing — fix: keep `^4.21.0`; migrate to 5 only as a dedicated change with routing tests.
2. [MINOR] `package.json:22-24` (`overrides.qs: 6.16.0`) — still REQUIRED, not stale. express 4.22.2 requires `qs ~6.15.1`; 6.15.3 is vulnerable to CVE-2026-82417 / GHSA-4mjr-xmp4-gh2g (medium, uncaught-exception DoS) and GHSA-x5fp-wj9c-mxmx, both fixed only in 6.16.0. `npm audit` = 0 solely because of the override; body-parser 1.20.8 alone only patches its own `~6.16.0` branch — release impact: removing the pin reintroduces a medium advisory into prod — fix: keep; add an inline rationale/ADR; drop only when express widens to `>=6.16`.
3. [MINOR] `.github/workflows/ci.yml:14-15,31` — actions use mutable tags (`actions/checkout@v4`, `actions/setup-node@v4`, third-party `codecov/codecov-action@v5`), not commit SHAs; no `.github/dependabot.yml` — release impact: tag-move/compromise executes in CI with `secrets.CODECOV_TOKEN`; no automated advisory PRs (the qs pin was hand-applied 3 days after disclosure) — fix: SHA-pin actions, add Dependabot for npm + github-actions.
