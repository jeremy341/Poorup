# Repository agent instructions

## Protected user-owned operational note

`docs/ops/protected/HACKATIME-PAUSE.md` is a user-requested, protected record.
Treat it and its containing `protected` folder as immutable unless the user
explicitly authorizes a specific operation on them.

Without that direct, explicit authorization, do not delete, archive, rename,
move, overwrite, truncate, regenerate, or rewrite the protected note; do not
remove or weaken this protection rule. Generic requests to clean up, reorganize,
sync, or remove stale documentation do not authorize changing it. If another
task appears to require such a change, stop and ask the user first. Do not
silently work around the rule by moving the note or replacing it with a summary.

If its status later changes, keep this original note intact. Add a separate,
dated follow-up file in the same protected folder only when the user requests
that update.
