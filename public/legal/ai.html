How deterministic bots and an optional external advisor make choices without owning the rules.

1. Bot modes

Poorup can run a local deterministic House Brain, an optional AI mode, or an automatic mode that prefers AI and falls back when the provider is unavailable. All bots use the same server-authoritative legal actions as a human player.

2. Decision context

Bot decisions can use the board, current turn, cash and obligations, loans, events, opponents’ public state, future rent risk, expected cash flow, and prior bot decisions. Private player messages, passwords, session tokens, hidden cards, raw account identifiers, and private loan terms must not be sent to an external provider.

3. What a decision means

An advisor returns a bounded suggestion from legal candidates. It cannot create money, ownership, dice, actions, or rules. The server rechecks every candidate and can reject stale, illegal, or unavailable choices. AI output can be wrong and is not financial, legal, or strategic advice.

4. External provider

If external AI is enabled, the effective notice will name the provider, endpoint region, categories of context sent, international-transfer mechanism, retention period, training use, subprocessors, and player controls. Until those facts are approved, external AI should remain disabled for public play.

5. Failure and fallback

Provider errors, quota exhaustion, malformed responses, or timeouts open a circuit and return control to the local House Brain. A player should see a clear status when a fallback occurs; the game must continue through the normal server seam or fail closed.

6. Player controls

The lobby should identify the selected bot brain. The operator must decide whether players can opt out of external AI entirely, whether existing rooms can change the mode, and how a request to delete or export AI-related records is handled.
